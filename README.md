# MeowPush Web SDK

Browser integrations for [MeowPush](https://meowpush.com).

| Package | Description |
| --- | --- |
| [@azurdream/meowpush-app-connect](packages/app-connect) | Connect a web application to MeowPush through explicit user authorization, using a built-in button or a headless API. |

The SDK has no runtime dependencies and provides ESM, TypeScript declarations and
a standalone browser script. The optional button includes Simplified Chinese and
English, light and dark themes, and connection progress.

See the [package guide](packages/app-connect/README.md) for integration examples
and [contributing guide](CONTRIBUTING.md) for development and release.
